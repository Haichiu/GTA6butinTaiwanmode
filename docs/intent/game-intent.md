# GTA6butinTaiwanmode — 確認版意圖

確認日期：2026-09-25

- **成品**：3D 低多邊形機車遊戲，網頁可玩，10～15 分鐘玩完，約 5～8 關，每關考一條台灣真實交通法規。
- **核心體驗**：輸給反直覺的法規，而不是技術。犯規 → 畫面定格 → 罰單（真實條號＋金額）＋「更危險卻罰更輕」的真實法規對比 → 秒速重來。
- **為什麼做**：個人興趣兼作品，免費放上 itch.io，丟連結就能玩。
- **成功標準**：有公開網頁連結；一般玩家不用教學能從第一關玩到結尾；每張罰單的條文都有查證出處。
- **限制**：Godot 4 + GDScript、只用免費素材（例如 Kenney CC0）、只做繁體中文、只支援電腦鍵盤、沒有期限。
- **分工**：使用者決定大方向；細部規劃、法規研究、程式與整合由 Claude 負責，不確定再問。
- **這一版不做**：行人篇、手機觸控、英文版、Steam 上架、自製美術、自編法規。

## 視角決定
3D 低多邊形 + 後上方跟隨鏡頭：保留 Asian Difficulty 的臨場崩潰感，同時看得清車道與待轉區。

## 法規查證原則
每一條都要查到《道路交通管理處罰條例》或相關法規的條號與罰鍰金額，並註明查證日期；查不到或與網路說法不符就回報，不放進遊戲。
